# Skill: Clarify Before Acting

## Purpose

Pause and ask 2–4 targeted questions when a task has ambiguous scope, missing constraints, or irreversible impact before executing.

## When It Triggers

Any task where scope, constraints, or impact are unclear.

## Step-by-Step Execution Rules

1. Identify ambiguity in the user's request.
2. Draft 2–4 targeted questions (one per uncertainty).
3. Present to user and wait for answers before proceeding.

## Output / Quality Check

User has answered all questions, or explicitly waived clarification.
