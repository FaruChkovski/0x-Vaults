# Skill: Sketch

## Purpose

Generate throwaway HTML mockups — 2-3 design variants to compare — so a design direction can be explored visually before committing to one. Each variant is a self-contained HTML file with real content and interactivity, verified in a browser.

- **License:** MIT (adapted from gsd-build/get-shit-done)
- **Installed in AvA's profile:** `C:/Users/faruc/AppData/Local/hermes/profiles/ava/skills/creative/sketch/`

## When to use

- User wants to see a design direction before building it
- Comparing layout A vs B, or 2-3 takes on a UI
- Mocking up a screen before committing to production code

## Core method

**Intake → Variants → Head-to-head → Pick winner (or iterate)**

1. **Intake:** Feel (adjectives/vibe), References (apps/sites), Core action (single most important user task)
2. **Variants:** 2-3 complete HTML files, each taking a different design stance (density, emphasis, aesthetic, layout, grounding)
3. **Head-to-head:** Present as a comparison table with an opinionated take
4. **Pick:** User chooses a winner, combines variants, or requests another round
